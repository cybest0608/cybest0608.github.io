MiraiChat

面向現代行動與桌面場景的專業級私密通訊平台。

Language / 言語 / 语言 / 語言: English · 日本語 · 简体中文 · 繁體中文

產品定位

MiraiChat 服務重視隱私、安全與多裝置連續體驗的使用者。

  • 一對一與群組即時通訊
  • 安全登入與工作階段管理
  • Android / iOS / Windows 跨平台支援

核心能力

1) 身分與存取安全

  • 帳號註冊與驗證登入
  • 以 session secret 進行後端授權
  • 可選生物辨識解鎖

2) 訊息與媒體傳輸

  • 加密訊息與附件交換
  • API + WebSocket 協同的可靠傳輸
  • 多裝置同步與狀態延續

3) 通知與可用性

  • Firebase Cloud Messaging 推播
  • 本地通知（含去重/靜音控制）
  • 背景訊息處理能力

安全設計

  • 憑證釘選（Certificate Pinning）
  • Keychain/Keystore 等級機密資料保護
  • 標準設定下採用 HTTPS/WSS
  • 本地資料分層儲存與隔離

合規與法務

請參閱 隱私權政策 了解資料處理細節。
