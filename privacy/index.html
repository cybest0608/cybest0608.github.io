Privacy Policy

Language / 言語 / 语言 / 語言: English · 日本語 · 简体中文 · 繁體中文

Effective Date: March 4, 2026
Application: MiraiChat
Operator: MiraiChat Team

This Privacy Policy explains what data MiraiChat may collect, how data is used, how data may be shared, and the controls available to users. This document is written to support transparency requirements under Google Play Data Safety and Apple App Privacy disclosures.

1. Data Collection

Depending on your feature usage, MiraiChat may collect and process the following categories:

  • Account and authentication data
  • Messaging and user content
  • Push and notification data
  • Device, security, and operational data
  • Permission-linked data processing

2. Data Usage

MiraiChat uses data to:

  • Create and authenticate user accounts
  • Deliver messages and media to intended recipients/devices
  • Maintain secure sessions and anti-abuse controls
  • Enable push notifications and in-app alerting
  • Store conversation/contact data locally for app functionality

3. Data Sharing

Data may be shared with backend chat/storage servers, push notification infrastructure, and purchase processors only when related features are used.

4. Data Storage and Retention

MiraiChat stores required data in secure device storage and app-local databases, and retention is tied to usage, local settings, and deletion workflows.

5. Data Deletion

Deletion can be triggered via logout/reset/deregister flows and remote file deletion APIs where available.

6. Contact Information

  • Privacy Contact: miraichat@hotmail.com
  • Support Contact: miraichat@hotmail.com
